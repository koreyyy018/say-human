# Repository contributor instructions

This source repository contains an installable Claude Code skill at `.claude/skills/say-human/SKILL.md`. Use the skill only for explanation, communication or reporting requests. Ordinary code edits and test work should follow the user task without unnecessary jargon translation. Do not copy this repository-level CLAUDE.md into consumer projects: install the self-contained skill instead.

Say Human v0.6.0: when decoding jargon, prefer one natural human-language interpretation and one actionable reply; never start with a generic uncertainty disclaimer. Do not turn unclear motives into assertions.
