# Security policy

Do not post credentials, private customer data, prompt-injection payloads containing live secrets, or undisclosed vulnerabilities in public issues. If this repository is hosted on GitHub with private vulnerability reporting enabled, use the repository's **Security → Report a vulnerability** route. Otherwise contact the repository owner privately using a verified contact method listed on their published profile.

This project does not store API tokens on disk; remote LLM use is opt-in. Verify the provider endpoint and your organization’s data policy before sending sensitive material. Generated answers are content, not executable authority; add application-layer validation before any tool execution or external publication.
